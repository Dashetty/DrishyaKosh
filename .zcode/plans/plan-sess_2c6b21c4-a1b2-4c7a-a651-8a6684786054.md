# Frame redesign: NeueBrucke titles, no genre tag, viewport-filling width

Three visual changes to the Frame component, per your screenshot. All changes are confined to `src/components/Frame.tsx` and `src/app/globals.css`. Sprocket rails stay as viewport decoration; hero and intertitles keep Maghfirea.

## 1. Video title → NeueBrucke, sentence case, vignette scrim behind

**Current** (`Frame.tsx:88`): title is Maghfirea via `font-display`, `text-[clamp(1.9rem,4.2vw,3.9rem)]`, relying on a text-shadow for legibility.

**Change:**
- `font-display` → `font-meta` (the NeueBrucke token), sentence case as-is (no uppercase/transform).
- Size: `text-[clamp(1.5rem,3vw,2.6rem)]` — NeueBrucke is a wider face; slightly smaller than the Maghfirea size so long titles fit the wider frame.
- Keep `[text-shadow:...]` and add a dedicated **scrim gradient** behind the title+credits block so it reads over any thumbnail: in globals.css extend the `.duotone::after` vignette OR (cleaner) add a second pseudo-element approach — a `.frame-scrim` class applied to the title container:

```css
/* globals.css — title scrim: dark gradient rising from the frame's bottom edge */
.frame-scrim {
  background: linear-gradient(
    to top,
    rgba(10, 9, 8, 0.92) 0%,
    rgba(10, 9, 8, 0.78) 28%,
    rgba(10, 9, 8, 0.35) 62%,
    transparent 100%
  );
}
```

Applied as an absolutely-positioned `inset-x-0 bottom-0 h-[42%]` layer inside the frame (below the text in z-order, above the img). This is the "vignette behind it" from your screenshot — a solid readable base under the title, heavier than the existing radial vignette.

- Also update the `.duotone::after` radial vignette: with the frame nearly full-bleed, strengthen it slightly (`0.55/0.82` → `0.65/0.9` at the outer stops) so the wide edges still read as film.

## 2. Remove the top-right genre tag

**Current** (`Frame.tsx:74-77`): a bordered pill showing `{video.genre.toUpperCase()}`.

**Change:** delete the whole `{/* genre tag · top-right */}` block. Genre still appears in the credits row (`CREATOR — YEAR — GENRE`), so no information is lost. The Frame component's `video.genre` field and the data model are untouched.

## 3. Frame fills width between the sprocket rails

**Current** (`Frame.tsx:59`): `w-[min(72rem,92vw)]` centered — a floating rectangle with large black margins.

**Change:**
- Frame width: `w-[min(72rem,92vw)]` → `w-[calc(100vw-7rem)]` (7rem total = 3.5rem per side, clearing the `left-4`/`right-4` sprocket rails at 14px wide plus breathing room). Below `lg` (where rails are hidden) fall back to near-full-width: `w-[calc(100vw-2.5rem)]` via responsive classes — `lg:w-[calc(100vw-7rem)]`.
- Max-width clamp kept at `100rem` so the frame never gets absurdly wide on ultrawide monitors (`w-full max-w-[100rem] lg:w-[calc(100vw-7rem)]` pattern — final Tailwind classes to be: `w-[calc(100vw-2.5rem)] lg:w-[calc(100vw-7rem)]` with `mx-auto`).
- Keep `aspect-video` (16:9). On a 1440×900 viewport the frame becomes ~1312×738 — ~82vh tall, consistent with the existing ~85vh intent, and 10% of neighbors still peek above/below while scrolling.
- Rounded corners `rounded-[1.25rem]` kept; the border, shadow, and duotone treatment are untouched.
- The pull-quote (desktop, right side) and WATCH button keep their current positions but sit on the wider frame; no coordinate changes needed since they're anchored to the frame's edges.
- Mobile (`<768px`) is unaffected — already near-full-width.
